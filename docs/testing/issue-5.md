# #5 自动化测试用例

| 测试用例编号 | 验证目的 | 测试步骤 | 预期结果 |
| --- | --- | --- | --- |
| JS-05-01 | 生效简历与搜索输入隔离 | 保存带合成身份信息的简历，审阅并确认去标识文本，提取方向后修改并确认，重新搜索 | 原始简历只留本机；提取和匹配只收到去标识版本，公开搜索只收到确认后的方向和筛选条件 |
| JS-05-02 | 验证硬条件边界和雇主归属 | 返回 35k–55k、25k–45k、51k–60k 及杭州外、区县不符、办公地点缺失、阿里/字节、蚂蚁/菜鸟、外包雇主的合成 JD | 按月薪区间、实际办公地点和招聘主体判定；办公地点缺失且其余条件符合时保留并标为待确认 |
| JS-05-03 | 验证匹配证据和投递入口 | 返回核实 JD 与摘要线索，捕获匹配输入，给出可回溯的匹配依据后登记投递 | 只有核实 JD 进入匹配；禁用公开搜索；页面展示 JD 和简历的依据，符合条件的职位可登记投递 |
| JS-05-04 | 验证真实订阅匹配 | 使用合成去标识简历和可核实 JD 走真实匹配入口 | 记录调用完成、输入范围和可回溯的匹配依据；不发送原始简历 |
| JS-05-05 | 分开判断 Base 和办公城市 | 提供明确合肥 Base 但不返回候选城市、带北航校区名的余杭地址、只写西湖区或余杭区的地址及两个办公地址 | 合肥 Base 排除；北航校区名不引入北京；西湖区办公城市待确认；余杭区可确认；两地标为冲突 |
