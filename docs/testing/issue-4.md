# #4 自动化测试用例

| 测试用例编号 | 验证目的 | 测试步骤 | 预期结果 |
| --- | --- | --- | --- |
| JS-04-01 | 核对公开搜索输入边界及订阅设置 | 保存合成岗位方向和一条手动 JD，从界面搜索；关闭 Fast 再搜索，捕获 Codex 进程实参和输入 | 两次均指定 ChatGPT 订阅、`gpt-6.1-sol`、`xhigh`；速度依次为 Fast、Standard；搜索只收到确认方向和筛选条件，不含手动 JD |
| JS-04-02 | 区分已核实 JD 和待核验线索 | 让受控来源分别返回可核实的正文、仅摘要的职位、无法佐证的正文 | 正文和原始出处可查；只有摘要或无法核实的职位标为待核验 |
| JS-04-03 | 搜索失败可见且可重跑 | 模拟未登录或调用失败，打开状态页；恢复后从界面重跑 | 显示明确的失败状态，恢复后能查看新的结果 |
| JS-04-04 | 验证真实订阅两种速度及官网 JD | 使用同一合成方向通过真实入口分别运行 Fast、Standard | 两次记录订阅设置和实际结果；至少一条官网 JD 可核实，记录公开搜索接收的字段 |
