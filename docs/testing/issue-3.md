# #3 自动化测试用例

| 测试用例编号 | 验证目的 | 测试步骤 | 预期结果 |
| --- | --- | --- | --- |
| JS-03-01 | 从投递维护一面 | 从已有投递新增一面，录入时间，修改时间后标为通过 | 投递显示「一面通过」，仍能查看修改后的预约时间 |
| JS-03-02 | 手动推进至二面并保留历史 | 增加二面及预约时间，再改为不通过；重启服务并打开同一投递 | 预约时显示「二面」和时间；更新后显示「二面不通过」，一面记录仍在 |
| JS-03-03 | 拒绝非法或串联到其他投递的轮次更新 | 提交非法时间、结果或属于另一条投递的轮次更新 | 原有进度不变，并能看见失败提示 |
