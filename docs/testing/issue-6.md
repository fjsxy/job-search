# #6 自动化测试用例

| 测试用例编号 | 验证目的 | 测试步骤 | 预期结果 |
| --- | --- | --- | --- |
| JS-06-01 | 验证转写稿归属和提交确认 | 在已登记投递的二面上传合成 `.txt` 或 `.md`；先预览，再确认 | 仅确认后启动订阅调用；只收到二面的转写稿并禁用公开搜索；一面记录不变 |
| JS-06-02 | 核对停止、补齐和保存状态 | 提交无法配对问题和回答的转写稿；根据提示补齐，再提交 | 第一次指出缺失片段且无复盘文件；第二次生成含问题概括、回答评价及优化点的文件，显示已保存 |
| JS-06-03 | 核对保存失败可恢复 | 指定无法写入的路径并提交，再修正目录重试 | 写入失败不显示已保存；修正后可在新目录打开生成的文件 |
| JS-06-04 | 验证真实订阅复盘路径 | 用合成转写稿通过真实入口验证成功、停止和补齐后重跑 | 记录真实订阅设置和文件结果，报告不包含真实面试材料 |
