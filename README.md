# 求职

用本机浏览器筛选职位、登记投递和面试，并从转写稿生成复盘。

需要 Node.js 22.13 或更新版本、npm 和 Make。使用订阅 Agent 前，安装 Codex CLI，并用 ChatGPT 订阅账号登录本应用的专用目录：

```sh
make login
make start
```

打开终端显示的地址（默认 `http://127.0.0.1:3000`）。只使用手动导入、投递和面试进度时，可直接运行 `make start`。

- **筛选职位**：保存原始简历，单独审阅并确认去标识文本；提取候选方向后，确认实际公开搜索方向。公司社招官网、脉脉和 BOSS 直聘分别显示执行状态。只有可核实的 JD 进入筛选，摘要或无法读取原文的职位保留原始链接供核对。
- **记录投递和面试**：粘贴 JD 可直接保存，从详情确认投递并维护各轮北京时间和结果。已投递的记录会随职位保留。
- **生成面试复盘**：在轮次页设置本机保存目录，上传 UTF-8 的 `.txt` 或 `.md`（最大 256 KiB），预览后确认提交。缺少关键问答时，页面会提示需要补齐的片段。
- **定时筛选**：本机服务运行时，每天北京时间 09:30 执行；关闭浏览器不影响后台。当天 09:30 后恢复服务且尚未执行时，当天尝试一次；错过的历史日期不补跑。打开搜索页可查看来源状态并手动重跑。

原始简历只保存在本机。公开搜索接收确认的岗位方向和筛选条件，匹配只接收去标识简历和已核实 JD，复盘只接收确认的转写稿。Agent 使用 ChatGPT 订阅、`gpt-6.1-sol` 和 `xhigh`，默认 Fast，可切换 Standard。本应用不加载个人 Codex 的指令或历史。

数据默认保存在 `.job-search-data/`，其中 `codex/` 用于专用登录。可用 `JOB_SEARCH_PORT` 和 `JOB_SEARCH_DATA_DIR` 指定端口和数据目录；设置自定义数据目录时，登录和启动使用同一设置。

```sh
make test
```
