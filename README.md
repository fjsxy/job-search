# 求职

需要 Node.js 22.13 或更新版本，以及 npm 和 Make。

```sh
make start
```

在浏览器打开终端显示的本机地址。粘贴 JD 正文并保存，在职位详情中确认投递。重启服务后，可从首页打开已保存的职位与投递。

使用官网搜索前，在终端运行 `codex login` 并选择 ChatGPT 登录。打开「官网搜索与 Agent 设置」，确认仅供公开搜索的岗位方向，再开始搜索。关闭页面后搜索继续运行，在结果页可以刷新状态或重跑。已核实的 JD 可从首页打开，只有摘要或正文无法核实的线索保留在当次结果页。Agent 默认使用 Fast，可切换到 Standard。

服务默认监听 `127.0.0.1:3000`，数据保存在仓库内的 `.job-search-data/`。可通过 `JOB_SEARCH_PORT` 和 `JOB_SEARCH_DATA_DIR` 指定其他本机端口和目录。

```sh
make test
```
